# FUNDAMED

OXU Fundamental tibbiyot kafedrasi uchun boshqaruv platformasi.

**Hozir:** `index.html` faylida o‘zbekcha sinov paneli mavjud. Vazifalarni qo‘shish, bajarilgan deb belgilash va o‘chirish mumkin. Ma’lumotlar faqat shu brauzerda saqlanadi (localStorage), boshqa xodimlarga ko‘rinmaydi.

**Hali yo‘q:** haqiqiy login, ko‘p foydalanuvchili umumiy ma’lumotlar bazasi, xavfsiz hujjat saqlash, serverdagi ruxsatlar va audit. Bu ishlab chiqarish tizimi emas. Maxfiy ma’lumot kiritmang.

**Keyingi bosqich:** autentifikatsiya, PostgreSQL, rollar, vazifalar, hujjatlar, hisobotlar va hosting.

**Diqqat:** repository hozir public. Parollar, maxfiy kalitlar va haqiqiy xodim/talaba ma’lumotlarini joylamang.
